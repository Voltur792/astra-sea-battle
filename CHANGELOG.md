# История изменений

## 0.3.2

- Если Astra предлагает корабли, которые соприкасаются, игра сохраняет допустимые позиции и переставляет конфликтующие; при тупиковой конфигурации создаётся допустимая расстановка локально.

## 0.3.1

- Исправлен формат ответов UI-вызовов, из-за которого Astra завершала bridge-вызов с gRPC `TypeError`.
- Разбор ответа модели теперь предпочитает JSON с результатом, даже если Astra повторила JSON запроса перед ним.
- При неверной расстановке показывается причина отказа валидатора, а не только общее сообщение.

## 0.3.0

- Добавлены быстрый режим без модели и режим против ИИ Astra.
- Долгие действия ИИ из карты выполняются в фоне; вкладка опрашивает статус, чтобы не ждать ответ модели внутри одного вызова bridge.
- Увеличен лимит вызова плагина до 15 минут и ожидание отдельного ответа модели до 4 минут.
- Ответы модели с JSON внутри поясняющего текста разбираются, а ходы и флот проверяются правилами игры.
- Запрос размещения флота передаётся как прямая инструкция; совместимость с ответом, повторяющим старый JSON-конверт, сохранена.
- Добавлены иконка плагина и совпадающая иконка вкладки.
- Подготовлены лицензия, переводы карточки, метаданные проекта и GitHub Actions workflow релиза.
