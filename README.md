# Морской бой для Astra

Морской бой внутри Astra: интерактивная карта, сохранение партий и два режима соперника.

## Режимы игры

- **Быстрая игра** — играйте без расхода ИИ.
- **Против Astra** — Astra расставляет корабли, отвечает на выстрелы и продолжает искать корабль после попадания. Расход зависит от выбранной модели и количества ходов.

Вкладка **«Морской бой»** показывает обе карты и историю выстрелов. Выберите режим перед стартом и стреляйте по неизвестным клеткам на карте Астры. Партии сохраняются между перезапусками Astra; история ограничена пятью играми, завершённые удаляются первыми.

Играть можно прямо на карте или называть координаты в чате.

## Установка

Скачать последнюю версию можно на странице [Releases](https://github.com/Voltur792/astra-sea-battle/releases). Чтобы играть против Astra, добавьте плагин в разделе разработки Astra и разрешите доступ к выбранной модели.
