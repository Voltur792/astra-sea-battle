# Морской бой для Astra

Морской бой внутри Astra: интерактивная карта, сохранение партий и два режима соперника.

## Режимы игры

- **Быстрый плагин** локально расставляет оба флота и выбирает ответные выстрелы. Запросов к модели нет, токены не расходуются.
- **Против ИИ Astra** использует настроенную модель Astra для расстановки её флота и выбора ответных выстрелов. Плагин отправляет компактные JSON-запросы, принимает JSON (в том числе если модель добавила вокруг него пояснение) и проверяет каждый ход перед применением. Запросы расходуют токены.

Если модель повторит прежнюю JSON-обёртку вместо результата, плагин также умеет извлечь из неё расстановку и проверить её по правилам поля.

Вкладка **«Морской бой»** показывает обе карты и историю выстрелов. Выберите режим перед стартом и стреляйте по неизвестным клеткам на карте Астры. Партии сохраняются между перезапусками Astra в каталоге пользовательских данных приложения.

Играть можно и через инструменты в чате. Активный ассистент передаёт расстановку флота и координаты через параметры инструментов; плагин проверяет правила: 10 кораблей длиной 4, 3, 3, 2, 2, 2, 1, 1, 1 и 1, без соприкосновения.

## Разрешения

Режиму «Против ИИ Astra» требуется `send_chat_message`, чтобы отправлять запросы с игровыми данными настроенной модели. Astra запрещает это разрешение для локально импортированного файла `.astraplugin`. Используйте установку из реестра либо загрузите папку через раздел разработки плагинов Astra и подтвердите разрешение. Быстрый режим это разрешение не использует.

## Разработка и сборка

Требуются Python, поддерживаемый установленной версией Astra, и CLI `astra-plugin`.

```powershell
astra-plugin check . --strict
astra-plugin test .
astra-plugin build .
```

Для разработки загрузите папку проекта через раздел Astra для плагинов разработчика. Релизный пакет создаётся GitHub Actions по тегу версии; локальный неподписанный архив не используется для публикации в реестре.
