# Морской бой для Astra

Морской бой внутри Astra: интерактивная карта, сохранение партий и два режима соперника.

❗❗❗ Важно: Для использования всех функций загрузите Source code (zip) через режим разработки Astra. Подробные шаги — в разделе [«Установка из исходников»](#установка-из-исходников).

## Режимы игры

- **Быстрая игра** — играйте без расхода ИИ.
- **Против Astra** — Astra расставляет корабли, отвечает на выстрелы и продолжает искать корабль после попадания. Расход зависит от выбранной модели и количества ходов.

Вкладка **«Морской бой»** показывает обе карты и историю выстрелов. Выберите режим перед стартом и стреляйте по неизвестным клеткам на карте Астры. Партии сохраняются между перезапусками Astra; история ограничена пятью играми, завершённые удаляются первыми.

Играть можно прямо на карте или называть координаты в чате.

## Установка

Скачать последнюю версию можно на странице [Releases](https://github.com/Voltur792/astra-sea-battle/releases). Чтобы играть против Astra, добавьте плагин в разделе разработки Astra и разрешите доступ к выбранной модели.

### Установка из исходников

Инструкция для Windows.

1. Откройте [последний релиз](https://github.com/Voltur792/astra-sea-battle/releases/latest), раскройте **Assets** и скачайте **Source code (zip)**. Архив исходников загружается как папка через Dev; выбирать его в окне импорта `.astraplugin` не нужно.
2. Распакуйте ZIP полностью в постоянную папку, например `C:\AstraPlugins\astra-sea-battle`. Откройте распакованную папку и найдите **`plugin.toml`** рядом с **`src`** и **`requirements.txt`**. Если архив создал ещё одну вложенную папку, выбирайте именно её.
3. В Astra откройте **Настройки → Приватность** и включите **«Разрешить неподписанные плагины»** для загрузки исходников.
4. Перейдите в **Плагины → Разработка (Plugins → Dev) → Загрузить плагин → Обзор**. Выберите папку с `plugin.toml` либо вставьте её полный путь в поле **Load a plugin** и нажмите загрузку.
5. Подтвердите запрашиваемые разрешения и дождитесь подготовки Python и зависимостей. Для первой установки нужен интернет; не закрывайте Astra до завершения.
6. Найдите плагин в **Установленных (Installed)** и включите его, если он выключен. После перезапуска Astra плагин из папки нужно включать снова.

Плагин запускается прямо из исходников Python; отдельная сборка не требуется. Если Astra сообщает, что Python не найден, установите 64-разрядный Python **3.11 или новее** и полностью перезапустите Astra.

**Если загрузка не удалась:** проверьте, что ZIP распакован целиком и выбрана папка с `plugin.toml`. При ошибке установки зависимостей проверьте интернет и откройте журнал в карточке плагина; ошибка `No module named ...` означает, что зависимости не подготовились. Установка пакетов в другой Python на компьютере не исправит окружение, которым Astra запускает плагин.

Откройте **Морской бой** и выберите режим игры. Для режима **«Против Astra»** подтвердите доступ плагина к чату с моделью. При ручном импорте `.astraplugin` этот доступ ограничен; загрузка исходников через Dev нужна для игры с моделью.

**Обновление из исходников:** распакуйте новый архив в отдельную постоянную папку, выключите старую копию, загрузите новую через Dev и включите плагин. Если настройки хранились в папке старой копии, сохраните её до переноса настроек. Не перемещайте и не удаляйте активную папку: Astra продолжает запускать код из неё.
